# Examples

| Mod | Language | Shows |
|---|---|---|
| [hello_rhai](https://github.com/SafeShows/Oxidizer/tree/master/examples/hello_rhai) | Rhai | callbacks, `this`, a window, a menu entry, a hook, by-name game access |
| [hello_rust](https://github.com/SafeShows/Oxidizer/tree/master/examples/hello_rust) | Rust | the `Mod` trait, a window, a menu entry, a hook |
| [bus_rust](https://github.com/SafeShows/Oxidizer/tree/master/examples/bus_rust) and [bus_rhai](https://github.com/SafeShows/Oxidizer/tree/master/examples/bus_rhai) | Rust and Rhai | events and services between a Rust and a Rhai mod, both ways: typed events, a retained topic, a busy error |
| [Rhai mod template](https://github.com/SafeShows/oxidizer-rhai-mod-template) | Rhai | typed game access, settings, a hotkey, a release workflow, a listing |
| [Rust mod template](https://github.com/SafeShows/oxidizer-rust-mod-template) | Rust | settings, a hotkey, a hook, install scripts, a release workflow for three platforms |
| [Flight Panel](https://github.com/SafeShows/oxidizer-flight-panel) | Rust | a full mod: flight data, a warp guard that skips a game method and changes a return value, settings, hotkeys |
| [Rhai Studio](https://github.com/SafeShows/oxidizer-rhai-studio) | Rust | text fields and tabs, drawing with ImGui draw lists, a window styled like the game's, `rhai_eval`, the log and mod states |

All of them are MIT No Attribution (the examples in the Oxidizer repository are MIT): copy what you need.
